## Contexto

O treinamento "Supervisor: Da Operação à Liderança" possui 8 módulos presenciais. O **Módulo 1 — A Função Estratégica do Supervisor** é o gancho mais forte para novos líderes e supervisores recém-promovidos. Esta landing page oferece o Módulo 1 como produto isolado (workshop avulso), servindo como entrada no funil de conversão do treinamento completo.

---

## Objetivo

Criar uma landing page evergreen de alta conversão para o Módulo 1, com:
- Inscrição direta via formulário
- Gatilho de urgência (vagas limitadas)
- Design consistente com o sistema existente
- Rota: `/treinamento/modulo-1`
