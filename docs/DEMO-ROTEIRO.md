# Roteiro de Demonstracao -- LIDERA Treinamentos

## Preparacao (antes da demo)
- Ter 2 abas abertas: site publico + admin
- Ter um celular para mostrar responsividade
- URLs: https://lideralearning.vercel.app (site) e /admin (painel)

## Parte 1: A Plataforma (5 min)

### 1.1 Pagina Inicial
- Mostrar o site publico
- Destacar: "Plataforma hibrida para elevar lideres"
- Mostrar os 3 pilares: Academy, Presencial, Corporativo

### 1.2 Programa Completo
- Navegar para /treinamento/modulos
- Expandir modulo 1 -- mostrar conteudo detalhado
- Destacar: 8 modulos, 2 dias, 16h, mentoria 30/60 dias

## Parte 2: Jornada do Lead (5 min)

### 2.1 Cadastro
- Abrir /treinamento/autoavaliacao em aba anonima
- Mostrar que pede cadastro
- Cadastrar com dados ficticios
- Mostrar tela de boas-vindas

### 2.2 Autoavaliacao
- Preencher o formulario de autoavaliacao
- Mostrar resultado: perfil + score
- Mostrar que PDI e gerado automaticamente
- "O lead recebe tudo isso por email"

## Parte 3: Painel do Gestor (10 min)

### 3.1 Dashboard
- Abrir /admin
- Mostrar KPIs reais
- Mostrar analise de autoavaliacoes (barras por dimensao)
- Mostrar status PDI por usuario

### 3.2 Pessoas
- Navegar para /admin/pessoas
- Mostrar tabela com todos os leads
- Clicar em um lead -> mostrar ficha completa
- Mostrar classificacao (Lead -> Aluno -> Gestor)

### 3.3 Avaliacoes
- Navegar para /admin/avaliacoes
- Mostrar respostas expandidas
- Tab Links -- copiar link do formulario para enviar

### 3.4 Treinamentos
- Mostrar turmas presenciais
- Mostrar controle de presenca
- Mostrar mentorias

### 3.5 Comercial (CRM)
- Navegar para /admin/comercial
- Mostrar pipeline Kanban
- Mostrar que leads do site ja aparecem automaticamente

### 3.6 Analytics
- Navegar para /admin/analytics
- Mostrar funil de conversao
- Mostrar distribuicao de perfis

### 3.7 Centro de Desenvolvimento
- Navegar para /admin/conteudo
- Mostrar os 8 modulos com conteudo completo
- "Aqui o Claudemir estuda e prepara os treinamentos"

## Parte 4: Academy (3 min)

### 4.1 Cursos Online
- Mostrar /dashboard/cursos
- Abrir uma aula
- Mostrar player de video
- Mostrar progresso e certificado

## Parte 5: Encerramento (2 min)

### 5.1 Diferenciais
- Formularios de diagnostico integrados
- PDI automatizado
- CRM para gestao comercial
- Turmas presenciais + online
- Analytics completo
- Emails automaticos

### 5.2 CTA
- "Quer ver na pratica? Faca seu diagnostico gratuito"
- Mostrar link: lideralearning.vercel.app/treinamento/autoavaliacao

## Dica para o Apresentador
- Foque no FLUXO, nao nas telas individuais
- Mostre a jornada: Lead -> Diagnostico -> PDI -> Treinamento -> Certificado
- Destaque a automacao: "O sistema faz isso sozinho"
